# RNF01 e RNF03 — Confirmação de Salvamento e PDF do Histórico

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar diálogo de confirmação antes de salvar receita (RNF01) e botão de exportação PDF no histórico de receitas do paciente (RNF03).

**Architecture:** Duas mudanças independentes em arquivos distintos — puro frontend JS/HTML. RNF01 intercepta o handler existente convertendo-o para async e inserindo um `await Swal.fire()` antes do fetch. RNF03 adiciona estado de módulo + botão no `modal-footer` + função `gerarPdfReceita()` reutilizando `html2pdf.js` já carregado globalmente.

**Tech Stack:** JavaScript vanilla, SweetAlert2 (já carregado via CDN no `_Layout.cshtml`), html2pdf.js (já carregado via CDN no `_Layout.cshtml`), Bootstrap 5 modal events, Razor Views (ASP.NET Core 8 MVC)

Adicionar a função `gerarPdfReceita()` após o listener acima e antes de `exportarExcel`:

```js
function gerarPdfReceita() {
    if (!receitaAtualParaPdf) return;
    const data = receitaAtualParaPdf;

    const btn = document.getElementById('btnGerarPdfReceita');
    btn.disabled = true;
    btn.innerHTML = '<i class="fas fa-spinner fa-spin"></i> Gerando...';

    const nomeSanitizado = nomePacienteAtual
        .normalize('NFD').replace(/[̀-ͯ]/g, '')
        .replace(/\s+/g, '_').replace(/[^a-zA-Z0-9_]/g, '');
    const filename = `receita_${nomeSanitizado}_${data.data.replace(/\//g, '-')}.pdf`;

    const medsHtml = data.medicamentos.map((m, i) =>
        `<tr style="background:${i % 2 === 0 ? '#f9f9f9' : '#fff'}">
            <td style="padding:5px 8px">${i + 1}</td>
            <td style="padding:5px 8px">${m.medicamento}</td>
            <td style="padding:5px 8px">${m.categoria}</td>
            <td style="padding:5px 8px">${m.tipo}</td>
            <td style="padding:5px 8px">${m.frequencia}</td>
            <td style="padding:5px 8px">${m.instrucoes.join(', ') || '—'}</td>
        </tr>`
    ).join('');

    const cidHtml = data.cids.map((c, i) =>
        `<tr style="background:${i % 2 === 0 ? '#f9f9f9' : '#fff'}">
            <td style="padding:5px 8px">${i + 1}</td>
            <td style="padding:5px 8px">${c.title || '—'}</td>
            <td style="padding:5px 8px">${c.code || '—'}</td>
        </tr>`
    ).join('');

    const cidSection = data.cids.length > 0
        ? `<h3 style="color:#4966b1;font-size:13px;margin:16px 0 6px;text-transform:uppercase;letter-spacing:.05em">Diagnósticos (CID-11)</h3>
           <table style="width:100%;border-collapse:collapse;font-size:11px">
               <thead><tr style="background:#4966b1;color:#fff">
                   <th style="padding:6px 8px;width:36px">#</th>
                   <th style="padding:6px 8px;text-align:left">Enfermidade</th>
                   <th style="padding:6px 8px;text-align:left">Código</th>
               </tr></thead>
               <tbody>${cidHtml}</tbody>
           </table>`
        : '';

    const adesaoTexto = data.adesao ? 'Sim' : 'Não';

    const html =
        '<div style="font-family:Arial,sans-serif;font-size:12px;padding:24px;color:#333">' +
            '<div style="text-align:center;border-bottom:2px solid #4966b1;padding-bottom:12px;margin-bottom:16px">' +
                '<h2 style="margin:0;color:#4966b1;font-size:20px">Receita</h2>' +
                '<p style="margin:4px 0 0;font-size:10px;color:#888">Sistema ICFT — Índice de Complexidade Terapêutica</p>' +
            '</div>' +
            '<table style="width:100%;margin-bottom:16px;font-size:12px"><tr>' +
                `<td><strong>Paciente:</strong> ${nomePacienteAtual}</td>` +
                `<td style="text-align:center"><strong>Data:</strong> ${data.data}</td>` +
                `<td style="text-align:right"><strong>ICT:</strong> ${data.ict.toFixed(2)} &nbsp;|&nbsp; <strong>Adesão:</strong> ${adesaoTexto}</td>` +
            '</tr></table>' +
            '<h3 style="color:#4966b1;font-size:13px;margin:0 0 6px;text-transform:uppercase;letter-spacing:.05em">Medicamentos</h3>' +
            '<table style="width:100%;border-collapse:collapse;font-size:11px">' +
                '<thead><tr style="background:#4966b1;color:#fff">' +
                    '<th style="padding:6px 8px;width:36px">#</th>' +
                    '<th style="padding:6px 8px;text-align:left">Medicamento</th>' +
                    '<th style="padding:6px 8px;text-align:left">Forma</th>' +
                    '<th style="padding:6px 8px;text-align:left">Tipo</th>' +
                    '<th style="padding:6px 8px;text-align:left">Frequência</th>' +
                    '<th style="padding:6px 8px;text-align:left">Instruções</th>' +
                '</tr></thead>' +
                `<tbody>${medsHtml}</tbody>` +
            '</table>' +
            cidSection +
            `<div style="margin-top:40px;border-top:1px solid #ddd;padding-top:10px;font-size:10px;color:#999;text-align:center">` +
                `Gerado em ${new Date().toLocaleDateString('pt-BR')} — Sistema ICFT` +
            '</div>' +
        '</div>';

    html2pdf().set({
        margin: 10,
        filename: filename,
        html2canvas: { scale: 2, useCORS: true, logging: false },
        jsPDF: { unit: 'mm', format: 'a4', orientation: 'portrait' }
    }).from(html).save().then(function () {
        btn.disabled = false;
        btn.innerHTML = '<i class="bi bi-file-earmark-pdf"></i> Gerar PDF';
    });
}
```
