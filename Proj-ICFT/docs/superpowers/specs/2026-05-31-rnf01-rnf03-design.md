# Design — RNF01 e RNF03: Confirmação de Salvamento e PDF do Histórico

**Projeto:** Proj-ICFT (TCC)
**Data:** 2026-05-31
**Autor:** Julian Reina (em colaboração com Claude)
**Status:** Aprovado para implementação

---

## 1. Contexto e motivação

Duas melhorias de UX no fluxo de receitas:

- **RNF01** — O botão "Obter ICT" em `Form.cshtml` dispara `fetch('/Home/SalvarReceita')` diretamente, sem nenhuma etapa de confirmação. Um clique acidental persiste a receita sem possibilidade de revisão.
- **RNF03** — O modal de detalhes de receita em `VerPaciente.cshtml` não oferece exportação em PDF. O profissional só pode gerar PDF no momento da criação (`Form.cshtml`); receitas já salvas no histórico não são exportáveis.

Ambas são mudanças isoladas em arquivos distintos. Nenhuma alteração de backend, migration ou serviço é necessária.

---

## 2. Escopo

| Feature | Arquivo | Tipo de mudança |
|---|---|---|
| RNF01 | `Views/Home/Form.cshtml` | Interceptar click handler, adicionar `await Swal.fire()` antes do fetch |
| RNF03 | `Views/Paciente/VerPaciente.cshtml` | Variável de estado + botão PDF no modal footer + função `gerarPdfReceita()` |

**Fora de escopo:**
- Alterações em controllers, services ou banco de dados
- Mudanças no template PDF existente de `Form.cshtml` (não deve ser alterado)
- Geração de PDF para evoluções clínicas

## 3. RNF01 — Confirmação ao Salvar Receita

### 3.1 Comportamento esperado

Ao clicar em "Obter ICT", antes de qualquer operação de rede, exibir um diálogo SweetAlert2 com:
- **Nome do paciente** — "Paciente Anônimo" se `#pacienteAnonimo` está marcado; nome selecionado no `#pacienteId` caso contrário
- **Quantidade de medicamentos** — `medicamentosAdicionados.length`
- **ICT estimado** — valor atual de `#ict-total` (já calculado e visível na tela)

Se o usuário cancelar, o handler retorna imediatamente. Se confirmar, o fluxo de save segue sem qualquer outra mudança.

### 3.2 Mudança no handler

**Antes:**
```js
$exportarBtn.on('click', function () {
    const pacienteId      = $('#pacienteId').val() || null;
    const pacienteAnonimo = $('#pacienteAnonimo').is(':checked');
    ...
    fetch('/Home/SalvarReceita', { ... })
```

**Depois:**
```js
$exportarBtn.on('click', async function () {
    const pacienteId      = $('#pacienteId').val() || null;
    const pacienteAnonimo = $('#pacienteAnonimo').is(':checked');
    const adesao          = $('#adesao').is(':checked');

    const pacienteNome = pacienteAnonimo
        ? 'Paciente Anônimo'
        : ($('#pacienteId option:selected').text().trim() || 'não identificado');
    const ictEstimado = document.getElementById('ict-total').textContent.trim();

    const confirmResult = await Swal.fire({
        icon: 'question',
        title: 'Confirmar salvamento?',
        html: `<p>Paciente: <strong>${pacienteNome}</strong></p>
               <p>${medicamentosAdicionados.length} medicamento(s) serão salvos.</p>
               <p>ICT estimado: <strong>${ictEstimado}</strong></p>`,
        showCancelButton: true,
        confirmButtonText: 'Salvar receita',
        cancelButtonText: 'Revisar',
        confirmButtonColor: '#198754'
    });
    if (!confirmResult.isConfirmed) return;

    // ... resto do handler existente sem alteração
    const payload = { ... };
    fetch('/Home/SalvarReceita', { ... })
```

### 3.3 Critérios de aceitação

1. Clicar em "Obter ICT" com medicamentos adicionados exibe o diálogo antes de qualquer requisição de rede
2. "Revisar" fecha o diálogo sem salvar; botão permanece habilitado
3. "Salvar receita" fecha o diálogo e executa o save normalmente (incluindo spinner e Swal de resultado)
4. O ICT exibido no diálogo corresponde ao valor calculado em tela (`#ict-total`)
5. Para paciente anônimo, exibe "Paciente Anônimo" no diálogo

## 4. RNF03 — PDF do Histórico de Receitas

### 4.1 Comportamento esperado

Ao abrir o modal de detalhes de uma receita em `VerPaciente.cshtml`:
- O botão "Gerar PDF" aparece no `modal-footer` após o carregamento dos dados
- Ao clicar, gera e baixa um PDF com o mesmo conteúdo visual do modal: cabeçalho, paciente, data, ICT, medicamentos, CIDs
- O nome do arquivo segue o padrão: `receita_NomePaciente_DD-MM-AAAA.pdf`
- Ao fechar o modal, o botão volta a ficar oculto

### 4.2 Estado externo

No topo do bloco `<script>`, junto às outras declarações de escopo de módulo:

```js
const nomePacienteAtual = '@Html.Raw(Model.NomePaciente)';
let receitaAtualParaPdf = null;
```

`nomePacienteAtual` é constante — a página já pertence a um paciente específico.
`receitaAtualParaPdf` é preenchida com o `data` de `DetalharReceita` após fetch bem-sucedido e limpa ao fechar o modal.

### 4.3 Botão no modal footer

```html
<div class="modal-footer">
    <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Fechar</button>
    <button type="button" class="btn btn-primary" id="btnGerarPdfReceita" style="display:none"
            onclick="gerarPdfReceita()">
        <i class="bi bi-file-earmark-pdf"></i> Gerar PDF
    </button>
</div>
```

### 4.4 Mudanças em `abrirReceita(id)`

Após `body.innerHTML = ...` (ao final do `.then(data => {...})`), adicionar:

```js
receitaAtualParaPdf = data;
document.getElementById('btnGerarPdfReceita').style.display = '';
```

### 4.5 Limpeza ao fechar o modal

```js
document.getElementById('modalReceita')
    .addEventListener('hidden.bs.modal', function () {
        receitaAtualParaPdf = null;
        document.getElementById('btnGerarPdfReceita').style.display = 'none';
    });
```

### 4.6 Função `gerarPdfReceita()`

Monta HTML equivalente ao template de `Form.cshtml`, substituindo as referências de dados pelos campos de `receitaAtualParaPdf`. Cores atualizadas para `#4966b1`. Nome do arquivo: nome do paciente sanitizado (espaços → underscores, acentos removidos via `normalize + replace`) + data da receita.

```js
function gerarPdfReceita() {
    if (!receitaAtualParaPdf) return;
    const data = receitaAtualParaPdf;

    const btn = document.getElementById('btnGerarPdfReceita');
    btn.disabled = true;
    btn.innerHTML = '<i class="fas fa-spinner fa-spin"></i> Gerando...';

    const nomeSanitizado = nomePacienteAtual
        .normalize('NFD').replace(/[̀-ͯ]/g, '')
        .replace(/\s+/g, '_').replace(/[^a-zA-Z0-9_]/g, '');
    const filename = `receita_${nomeSanitizado}_${data.data.replace(/\//g, '-')}.pdf`;

    let medsHtml = data.medicamentos.map((m, i) =>
        `<tr style="background:${i % 2 === 0 ? '#f9f9f9' : '#fff'}">
            <td style="padding:5px 8px">${i + 1}</td>
            <td style="padding:5px 8px">${m.medicamento}</td>
            <td style="padding:5px 8px">${m.categoria}</td>
            <td style="padding:5px 8px">${m.tipo}</td>
            <td style="padding:5px 8px">${m.frequencia}</td>
            <td style="padding:5px 8px">${m.instrucoes.join(', ') || '—'}</td>
        </tr>`
    ).join('');

    const cidHtml = data.cids.map((c, i) =>
        `<tr style="background:${i % 2 === 0 ? '#f9f9f9' : '#fff'}">
            <td style="padding:5px 8px">${i + 1}</td>
            <td style="padding:5px 8px">${c.title || '—'}</td>
            <td style="padding:5px 8px">${c.code || '—'}</td>
        </tr>`
    ).join('');

    const cidSection = data.cids.length > 0
        ? `<h3 style="color:#4966b1;font-size:13px;margin:16px 0 6px;text-transform:uppercase;letter-spacing:.05em">Diagnósticos (CID-11)</h3>
           <table style="width:100%;border-collapse:collapse;font-size:11px">
               <thead><tr style="background:#4966b1;color:#fff">
                   <th style="padding:6px 8px;width:36px">#</th>
                   <th style="padding:6px 8px;text-align:left">Enfermidade</th>
                   <th style="padding:6px 8px;text-align:left">Código</th>
               </tr></thead>
               <tbody>${cidHtml}</tbody>
           </table>`
        : '';

    const adesaoTexto = data.adesao ? 'Sim' : 'Não';

    const html =
        '<div style="font-family:Arial,sans-serif;font-size:12px;padding:24px;color:#333">' +
            '<div style="text-align:center;border-bottom:2px solid #4966b1;padding-bottom:12px;margin-bottom:16px">' +
                '<h2 style="margin:0;color:#4966b1;font-size:20px">Receita</h2>' +
                '<p style="margin:4px 0 0;font-size:10px;color:#888">Sistema ICFT — Índice de Complexidade Terapêutica</p>' +
            '</div>' +
            '<table style="width:100%;margin-bottom:16px;font-size:12px"><tr>' +
                `<td><strong>Paciente:</strong> ${nomePacienteAtual}</td>` +
                `<td style="text-align:center"><strong>Data:</strong> ${data.data}</td>` +
                `<td style="text-align:right"><strong>ICT:</strong> ${data.ict.toFixed(2)} &nbsp;|&nbsp; <strong>Adesão:</strong> ${adesaoTexto}</td>` +
            '</tr></table>' +
            '<h3 style="color:#4966b1;font-size:13px;margin:0 0 6px;text-transform:uppercase;letter-spacing:.05em">Medicamentos</h3>' +
            '<table style="width:100%;border-collapse:collapse;font-size:11px">' +
                '<thead><tr style="background:#4966b1;color:#fff">' +
                    '<th style="padding:6px 8px;width:36px">#</th>' +
                    '<th style="padding:6px 8px;text-align:left">Medicamento</th>' +
                    '<th style="padding:6px 8px;text-align:left">Forma</th>' +
                    '<th style="padding:6px 8px;text-align:left">Tipo</th>' +
                    '<th style="padding:6px 8px;text-align:left">Frequência</th>' +
                    '<th style="padding:6px 8px;text-align:left">Instruções</th>' +
                '</tr></thead>' +
                `<tbody>${medsHtml}</tbody>` +
            '</table>' +
            cidSection +
            `<div style="margin-top:40px;border-top:1px solid #ddd;padding-top:10px;font-size:10px;color:#999;text-align:center">` +
                `Gerado em ${new Date().toLocaleDateString('pt-BR')} — Sistema ICFT` +
            '</div>' +
        '</div>';

    html2pdf().set({
        margin: 10,
        filename: filename,
        html2canvas: { scale: 2, useCORS: true, logging: false },
        jsPDF: { unit: 'mm', format: 'a4', orientation: 'portrait' }
    }).from(html).save().then(function () {
        btn.disabled = false;
        btn.innerHTML = '<i class="bi bi-file-earmark-pdf"></i> Gerar PDF';
    });
}
```

### 4.7 Critérios de aceitação

1. Ao abrir qualquer receita no modal de VerPaciente, o botão "Gerar PDF" aparece no footer
2. Ao clicar, o PDF é gerado e baixado com nome `receita_NomePaciente_DD-MM-AAAA.pdf`
3. O PDF contém: cabeçalho ICFT, paciente, data, ICT, adesão, tabela de medicamentos, tabela de CIDs (se houver)
4. Cores do PDF usam `#4966b1` (não `#007bff`)
5. Ao fechar o modal e reabrir outra receita, o botão funciona corretamente com os novos dados
6. O botão exibe spinner durante a geração e é reabilitado após conclusão
